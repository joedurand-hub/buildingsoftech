# Mystica screenshots

The Store-ready sets in `en`, `es`, `pt`, and `fr` are real 1080 x 1920 captures of the Expo app running with its actual SQLite-backed horoscope engine. They cover onboarding, personalization, the generated daily reading, the three editorial areas, and the shareable Story preview.

Deferred interface locales: `vi`, `id`, `de`, `pl`, `uk`, `ru`, `zh`, `ja`, and `ko`. Their Store metadata exists, but screenshot sets must not be presented as localized until the app UI and generated reading banks are complete in those languages.

`es/06-premium.png` is QA evidence only. It is excluded from the public Store manifest because the local browser build cannot load real RevenueCat prices.

See `../screenshots-manifest.json` for dimensions, feature mapping, locale status, and SHA-256 checksums.
