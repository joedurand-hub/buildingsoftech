# New app public package

1. Copy this directory to `apps/<slug>`.
2. Replace all `{{PLACEHOLDER}}` values and remove `noindex` only when content is final.
3. Add real, release-specific store screenshots under `assets/screenshots/`.
4. Validate `app.json` against `../app.schema.json`.
5. Add the public card to `../catalog.js`.
6. Mark readiness fields true only after manual review against the shipping build and store setup.

Do not publish generic legal text without adapting data collection, account deletion, health/safety claims, user-generated content, and monetization to the actual app.
